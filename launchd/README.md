# Historical LaunchAgent templates

These are legacy examples, not files installed by the Mac package. They contain
literal placeholders (`YOUR_MAC_USER`, model paths); launchd will not expand them.
Do not copy/load them unchanged. Use the [current installer](../INSTALL.md),
which generates absolute paths for the actual user, virtual environment and
owned service. No personal login, model path or SSH address ships in these
examples. Existing services are not rewritten by editing these templates.

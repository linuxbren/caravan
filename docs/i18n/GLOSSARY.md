# Localization glossary

Words Caravan reuses a lot, so every language file can stay consistent.
Spanish (Day 32) is neutral Latin American / universal Spanish, with the
casual *tú* tone the English text already has. Model names, the product
name **Caravan**, **Mini**, **GGUF**, **MLX**, command lines and code
identifiers stay in English.

| English | Spanish | Notes |
|---|---|---|
| model | modelo | A model on disk or in the catalog. |
| Models | Modelos | The catalog drawer. |
| split | reparto / repartir | Running one model across more than one Mac. Not "split" in Spanish. |
| layers | capas | Model layers on a Mini. |
| tokens | tokens | Kept in English; usual in this field. |
| token | token | Same. |
| context | contexto | The model's context window (Day 31 wording). |
| quant | cuantización | When it names a file or a row in the catalog, "quant" may stay as a short label if it is next to a technical name; running text uses "cuantización". |
| Load | Cargar | Button. Cloud models also say Cargar, not Descargar. |
| Download | Descargar | Button. |
| Unload | Descargar de memoria | Not the same as Descargar (a file). If space is tight: "Quitar". Prefer "Descargar de memoria" in help text and "Quitar" on a short button if needed. |
| Settings | Ajustes | The right-hand drawer. |
| Mini | Mini | Stays English. Plural: Minis. |
| Mac | Mac | Stays English. Plural: Macs. |
| Caravan | Caravan | Product name, never translated. |
| GGUF, MLX | GGUF, MLX | Format names, never translated. |
| Chat | chat | The conversation view. |
| Queue | Cola | The Send button while a reply is written. |
| Stop | Detener | Ends the reply on the Macs. |
| Update | Actualizar | |
| Topology | Topología | |
| placement | ubicación | Where a model runs (1 Mini / split / copy to all). |
| Copy to all | Copiar a todos | |
| recommended | recomendado | |
| beta | beta | Mark on a language in the picker until a native speaker reviews it. |
| Apply & restart | Aplicar y reiniciar | |
| Auto-tune | Autoajuste | |
| Self-tuning | Autoajuste | |
| hugging face / Hugging Face | Hugging Face | Product name. |
| Ollama Cloud | Ollama Cloud | Product name. |
| tailnet / Tailscale | Tailscale | Product name; "tu red de Tailscale" in running text. |
| Remote Login | Inicio de sesión remoto | macOS setting name, explained in Spanish. |
| on / off | activado / desactivado | Switches. Short: Sí / No is too vague; prefer Activado / Desactivado, or On / Off if the control is too narrow. Spanish screens use Activado / Desactivado. |

Numbers in Spanish use a decimal comma and a period as the thousands
separator (1.234,5). Lists of words use "y" and "o". Dates look like
"13 de noviembre" and "noviembre de 2026".

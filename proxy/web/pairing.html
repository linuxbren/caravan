Your Macs, together

Install Caravan on the new Mac. Keep both Macs on the same home network or connect them with a Thunderbolt cable.

Checking this Mac…

On the new Mac

Turn on Remote Login for the account you are using. Caravan needs this Mac permission to work together. Do not open Remote Login to the internet.

Then show a code here. On your first Mac, click Add this Mac and enter this code. Only someone you trust should see it.

On the first Mac

Find the new Mac below. Check its name and use the code shown on that Mac. Caravan saves the connection for you. It will work out what fits when you choose a model.

Connected Macs

Unload your model before removing a Mac. If that Mac is offline, Caravan will finish removing its connection when it returns. Your model files are kept.

Pairing is new. Use it only on a home network, a cable, or a private tailnet you trust. Adding a Mac gives the first Mac permission to start Caravan programs in this account. Details and help.
